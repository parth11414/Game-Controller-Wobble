# Browser games surface

## Mode

Experience

## Visitor success

Friends can select WOBBLE or Ping Pong, pair phones with the same room, understand connection and player state, and start playing together.

## First viewport

Keep the selected game and its live playfield dominant. The header exposes game selection, server state, room/player count, and an invite action. A persistent pairing panel shows the real QR code and room code, plus keyboard play when a phone is not available.

## Product truth to preserve

- WOBBLE remains the four-player rolling and star-collecting game with holes, jump, dash, and keyboard controls.
- Ping Pong remains one-phone-versus-computer or two-phone head-to-head play to five, with tilt, serve, and power actions.
- Room creation, QR pairing, room-code entry, WebSocket state, reconnection, and the mobile controller protocol continue to work.
- The controller app is outside this surface and is not redesigned here.
